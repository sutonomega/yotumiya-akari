# Ideas

Yorumiya AI の思いつきメモです。
ここにある項目は、まだ設計や実装予定として確定していません。
実装方針が固まったものは `roadmap.md` へ移します。

## 発話と人格

- 時報の季節感を強める。
- 生活ログから、無理のない一言を作る。
- 自分育成AIとして、長期的な変化を少しずつ反映する。

## 入力とイベント

- カレンダー以外の生活イベントを検知する。
- 動画視聴や作業状況を実況の文脈として扱う。
- 天気や気温を時報の雰囲気に反映する。

## 出力と運用

- X投稿の dry-run ログを見やすくする。
- WebUI で現在の状態、次回投稿、直近出力を確認できるようにする。
- WebUI で `time_signal_fallbacks.json` を確認できるようにする。
- 音声出力と投稿文の雰囲気を分けて調整する。
- SNS投稿用の `daily4` と、ESP32時報用の `hourly` を別 queue / 別 target として分ける。
